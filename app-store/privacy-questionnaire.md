# App Privacy preparation

These answers are a submission worksheet. Re-check them against the production build immediately before submitting App Privacy in App Store Connect.

## Data linked to the user

- Contact Info → Email Address
  - Purpose: App Functionality
  - Used for tracking: No
- User Content → Other User Content (nickname and system avatar identifier)
  - Purpose: App Functionality
  - Used for tracking: No
- Identifiers → User ID and Device ID
  - Purpose: App Functionality, Fraud Prevention, Security
  - Used for tracking: No
- Usage Data → Product Interaction (focus-session start/end time and duration)
  - Purpose: App Functionality
  - Used for tracking: No

## Not collected

- The user's Family Controls application tokens or selected-app identity
- Audio recordings or microphone data
- Precise or coarse location
- Contacts, photos, messages, browsing history, search history, health, fitness, financial, purchase, advertising, or diagnostics data

## Privacy behavior

- Email addresses are encrypted at rest and masked on all public surfaces.
- Unverified accounts never appear on the public leaderboard.
- Users can delete their account and associated server data from inside the app.
- Data is not sold, used for third-party advertising, or used for cross-app tracking.
